SAATHI-AI — DOMAIN KNOWLEDGE


PURPOSE
Saathi-AI is a Smart Safety System Assistant designed as an elderly safety companion. Its purpose is to support safer and more independent living for elderly people through emergency detection, alerts, location sharing, voice assistance, and family/caregiver communication.


CORE IDEA / SOLUTION


1. MULTI-LEVEL EMERGENCY DETECTION
Saathi-AI uses multiple checks before escalating an emergency:
- Event detected through camera/sensor.
- Voice check can be used to confirm the user's condition.
- Motion and sensor verification can help validate an event.
- If there is no response or an emergency is confirmed, an alert can be triggered.
- The system is designed to reduce false alarms by combining multiple signals rather than relying on a single detection.


2. AI-ROUTINE LEARNING
Saathi-AI includes an AI routine-learning concept for understanding an elderly user's normal routine.
The concept is intended to:
- Learn the user's daily routine.
- Identify unusual deviations from the learned routine.
- Support early detection of potentially unsafe situations.
- Improve the relevance of emergency responses over time.
Routine learning is an assistance mechanism; it should not be treated as a medical diagnosis.


3. DIGITAL TWIN
Saathi-AI proposes a digital-twin concept for maintaining a digital representation of relevant user safety information.
The digital twin is intended to support:
- User profile and important safety information.
- Emergency context and relevant events.
- Health/safety-related information provided for the system's operation.
- Monitoring and decision support.
- Personalized emergency assistance.


4. SOS BUTTON
The SOS button provides a direct emergency pathway.
Planned capabilities include:
- One-touch SOS activation.
- Sharing the user's location.
- Identifying/communicating with the nearest relevant emergency facility.
- Sending emergency alerts to family members and caregivers.
- Supporting emergency calling/communication.
- Providing emergency context to contacts.


PROBLEMS AND PROPOSED RESOLUTIONS


Language barriers:
- Saathi-AI uses a multilingual AI voice assistant.
- It is intended to support regional-language voice assistance, voice commands, and spoken emergency guidance.


User may be unable to press SOS:
- Automatic emergency detection is intended to trigger assistance when the user cannot manually press the SOS button.


Elderly person may fall when alone:
- AI camera-based fall detection is proposed to identify a possible fall.


False alarms from sensors:
- Multi-level AI and sensor verification is used to validate an event before triggering an alert.


Emergency may go unnoticed:
- Voice confirmation can be used to ask the user whether they are okay.


Family lacks real-time information:
- Live location and emergency-context sharing are intended to keep family/caregivers informed.


TECHNICAL APPROACH


METHODOLOGY / PROCESS
The proposed workflow is:
1. User registers/logs in.
2. User or the system triggers an SOS/emergency event.
3. The request/event is processed.
4. Relevant data is stored and managed.
5. An alert manager handles the emergency.
6. Alerts are sent to the appropriate contacts/services.


TECHNOLOGIES PROPOSED
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Cloud storage: Firebase
- Maps and location: Maps API
- Notifications: Firebase Cloud Messaging (FCM)
- Authentication: JWT / Firebase Auth
- Hosting: Firebase Hosting

FEASIBILITY / RISKS AND MITIGATION


1. False fall/emergency detection
Risk: Wrong detection may lead to false alarms.
Mitigation: Use camera + sensor + voice confirmation / multi-level verification.


2. Privacy concerns with camera
Risk: Continuous monitoring may raise privacy concerns.
Mitigation: Prefer edge processing, process data locally where possible, and avoid strong continuous video monitoring.


3. Internet/network failure
Risk: Poor connectivity may delay alerts.
Mitigation: Provide offline fallback, local detection and SMS/call alerts when internet is unavailable.


4. Sensor failure
Risk: Faulty sensor data can affect system accuracy.
Mitigation: Cross-check multiple sensors and validate using multiple sources before triggering an alert.


5. Power failure
Risk: Power loss can stop the system from working.
Mitigation: Use battery/UPS backup for critical components.


6. Limited computing resources
Risk: AI processing may be heavy for low-power devices.
Mitigation: Use lightweight AI models and optimized models/edge devices to reduce computational load.


IMPACT AND BENEFITS


KEY BENEFITS FOR USERS AND SOCIETY
- Safer and independent living: helps elderly individuals live alone with dignity, safety and confidence.
- Faster emergency response: early detection and automatic alerts can reduce response time during health or critical situations.
- Family peace of mind: families can stay informed with real-time alerts and context.
- Reduced caregiver burden and costs: prevents serious incidents and unnecessary timely intervention where appropriate, helping reduce medical expenses and long-term care costs.
- Better quality of life for all: improves overall well-being of elderly individuals and strengthens their communication with communities.
